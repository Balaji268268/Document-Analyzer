# 🚀 Render.com Deployment Guide for DocSummarizer

Deploy **DocSummarizer** for **100% FREE** on **Render.com** with **zero daily CPU quota caps** and an instant public HTTPS URL (`https://<your-app>.onrender.com`).

---

## 1-Click Free Deployment Instructions:

1. **Log in / Sign up to Render**:
   - Open [dashboard.render.com](https://dashboard.render.com) and log in with your **GitHub account**.

2. **Create a New Web Service**:
   - Click **New +** → **Web Service**.
   - Select **Build and deploy from a Git repository**.

3. **Connect GitHub Repository**:
   - Choose repository: **`Balaji268268/Document-Analyzer`**.

4. **Configure Settings**:
   - **Name**: `document-analyzer`
   - **Language / Environment**: **Docker** *(Render auto-detects `Dockerfile`)*
   - **Region**: Select your preferred region (e.g. Singapore / Oregon / Frankfurt).
   - **Branch**: `master`
   - **Instance Type**: Select **Free** ($0/mo).

5. **Deploy**:
   - Click **Create Web Service**.
   - Render will build your Docker image and provide your live URL:
     `https://document-analyzer-xxxx.onrender.com`

---

🎉 **Done!** Every time you push code to GitHub (`master`), Render automatically updates your live website for free!
